Executive Summary

MSC 111 的核心意義：從「技術可行」走向「法規落地」

本次會議可視為海事安全規範面對新燃料、新通訊、新檢查技術與自主船舶的一次重要更新。 對船東、船廠、船級社與設備廠而言，重點不只是「何時生效」，更重要的是在新造船設計、 船員訓練、設備選型與管理系統中提前建立可驗證的合規路徑。

航運業實務提示

  • 立即行動：氫氣、氨氣及甲醇燃料相關船員培訓指南已即時生效，建議儘早檢視訓練矩陣與 SMS 文件。
  • 新造船專案：IP Code、Load Line、SRtP、IGC/IGF 等更新涉及合約日、龍骨日與交船日，設計初期應先確認適用基準。
  • 長期追蹤：MASS 強制法規雖以 2032 年為目標，但實務上仍可能延後，建議持續追蹤 MSC 112 與後續 EBP 討論。
Key Effective Dates

重要生效時程一覽

以專案管理角度，建議將下列日期放入新造船規格、設計審查與合規追蹤表。

即時生效

氫燃料船舶安全指南、電子航海出版品（ENP）指南、導航通訊軟體維護指南、甲醇／乙醇與氨燃料船員培訓指南。

2026.07.01

非強制性 MASS 法規生效；氨氣貨物作燃料指南生效。

2028.01.01

VDES 導入、2011 ESP Code 修訂、GMDSS 相關 SOLAS 修訂等多項規範開始適用。

2028.07.01

IGC Code 修訂、IGF Code 與 SOLAS II-1 修訂預計生效。

2031–2032

自由落下救生艇修訂自 2031 年起適用；IP Code 交船適用與強制性 MASS 法規目標落在 2032 年。

01
Maritime Autonomous Surface Ships

自主水面船舶（MASS）

MSC 111 讓 MASS 從概念討論進一步走向全球監管框架，並將 ROC、船長責任與 ISPS 適用性納入討論重點。

已採納

非強制性 MASS 法規正式採納

建立自主船舶監管基礎框架，補足現行 SOLAS 等公約對 MASS 的適用空白。 會議確認遠端操控中心（ROC）可視為與航行駕駛台直接相關的地點；當船上有船員時，船長須親自在場。 ROC 亦應適用 ISPS Code。

生效日：2026 年 7 月 1 日
持續推進

強制性 MASS 法規開發啟動

經驗積累階段（Experience-Building Phase, EBP）框架草案將於 MSC 112 繼續討論。 目標生效日維持 2032 年 1 月 1 日，但委員會已承認 2036 年可能更具實務可行性。 MASS 與 ROC 證書模板僅作為範例，各主管機關仍需自行制定格式。

目標生效：2032 年 1 月 1 日
02
Alternative Fuels & New Technologies

替代燃料與新技術安全規範

本次會議對氫、氨、LPG、乙烷、CO₂ 貨物與低閃點燃料的規範邊界做出更清楚的安排。

已批准

IGC Code 修訂：液化氣體運輸船

修訂涵蓋氨氣、LPG、乙烷燃料使用與 CO₂ 貨物運輸等議題。 為回應業界對溯及適用的疑慮，採用合約日、龍骨安放日與交船日三日期制度。 同時明確 IGC Code 不適用於非氣體運輸船，落實「一船一規範」原則。

預計生效：2028 年 7 月 1 日（MSC 112 採納後）
已批准

IGF Code 與 SOLAS II-1 修訂

修訂確認 IGF Code 不適用於氣體運輸船，並統一 SOLAS 與 IGF Code 中「氣體燃料」與「低閃點燃料」的定義， 以消除過往法規語意不一致所造成的設計與審查疑義。

預計生效：2028 年 7 月 1 日
已批准 / 即時生效

氫氣、氨氣與甲醇／乙醇燃料相關指南

船用氫燃料安全臨時指南即時生效，涵蓋液態與壓縮氫，並採目標導向架構。 氨氣貨物作燃料臨時指南通過，支援 IGC Code 第 16.9 條應用。 甲醇／乙醇與氨燃料船員培訓指南也同步批准，並以 LNG 訓練標準作為發展基礎。

氫氣與培訓指南：即時生效
03
Ship Design & Construction

船舶設計與建造（SDC）

這一組更新對新造船設計、穩性計算、結構檢查與客船安全返港分析具有實務影響。

已採納

IP Code：工業人員重量標準上調

穩性計算基準由 75 kg 提高至 90 kg，適用於 2028 年 1 月 1 日後簽訂合約的新造船。

合約日 2028.01.01 後適用
已採納

1988 Load Line Protocol 修訂

開放甲板護欄最低高度須達 1 m，以降低惡劣天候下船員落海風險。適用於 2028 年 1 月 1 日後安放龍骨之 24 m 以上新造船。

龍骨安放 2028.01.01 後適用
已採納

2011 ESP Code：遠端檢查技術（RIT）

允許以遠端檢查技術替代近距離結構檢查。RIT 業者認證有效期為 3 年，且需符合 Annex 4 性能要求。

生效日：2028 年 1 月 1 日
已批准

客船安全返港（SRtP）說明文件修訂

擴大適用範圍，納入替代燃料與完整生命週期。新增系統分類 1A、1B、2、3 類，並建議主管機關於設計初期即介入。

適用：120 m 以上或 3 個以上主垂直分區之客船
04
Navigation, Communications, Search & Rescue

航行與通訊（NCSR）

NCSR 相關決議反映航海通訊數位化、衛星定位多元化與軟體維護治理的重要性。

已採納

VDES（VHF Data Exchange System）正式導入

修訂 SOLAS V/18、V/19 以及 1994／2000 HSC Code，允許船舶搭載 VDES 設備，進一步提升船舶通訊與數據交換能力。

生效日：2028 年 1 月 1 日
已採納

北斗衛星（BDS）性能標準修訂與 GNSS 增強系統認可

BDS 性能標準更新支援雙頻並提升定位精度；同時建立 SBAS、RAIM 等 GNSS 增強系統的正式 IMO 認可程序。

適用：2028 年 7 月 31 日後安裝之設備
已批准

電子航海出版品（ENP）與軟體維護指南

ENP 使用指南即時生效，針對非 ECDIS 的數位化出版品提供統一方向。導航通訊設備軟體維護指南則涵蓋網路安全、遠端維護與電子服務報告等要求。

即時生效
05
Ship Systems, Equipment & Other Matters

救生設備（SSE）與其他重要事項

除救生設備外，本次會議也推進網路風險管理、FRP 火災安全與遠端審核／檢查的制度化。

已採納

自由落下救生艇 LSA Code 修訂

新增無需下水即可測試脫離系統的裝置設計要求；安全係數最低 6 倍，且需採用耐腐蝕材料，不需塗裝或鍍鋅。

適用：2031 年 1 月 1 日後安裝之救生艇
已批准

網路安全與 ISPS Code

海事網路風險管理指南修訂 Rev.4 獲批准，納入 IAPH 新興技術網路韌性指引。非強制性海事網路規範路線圖通過，目標 2028 年完成，並預計於 2027 年召開跨期工作組會議。

已批准

FRP 結構指南修訂與遠端檢查指南

FRP 火災安全臨時指南修訂通過，新增荷載與非荷載構件測試方法，包括溫度法與撓度法兩種選項。遠端檢查、ISM 審核與 ISPS 驗證指南也正式確立，讓疫情後發展出的遠端作業模式取得更明確的法規支持。

建議後續追蹤清單

可將下列項目放入專案例會、法規追蹤表或新造船規格審查清單中。

01｜設計階段 確認合約日、龍骨日與交船日對 IP Code、Load Line、IGC/IGF、SRtP 與 ESP Code 的適用性。
02｜營運管理 更新 SMS、船員訓練矩陣與替代燃料操作程序，特別是氫、氨、甲醇／乙醇相關要求。
03｜設備與供應商 追蹤 VDES、BDS、ENP、軟體維護、遠端檢查技術與救生艇脫離系統的設備認證要求。
對船東： 重點是把生效日轉換成船隊管理與新造船專案的實際檢查點。
對船級社／檢驗端： 重點是提前釐清審查依據、證書格式、遠端檢查邊界與主管機關接受度。
