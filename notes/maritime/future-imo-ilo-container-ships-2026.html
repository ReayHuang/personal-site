SURVEYOR'S READING METHOD

這不是單純的「未來法規目錄」

身為驗船師，我閱讀這類 Future Legislation 報告時，最關心的不是記住所有 Item number，而是先判斷每一項要求目前位於哪個法規階段，再確認觸發日期與適用範圍，最後把條文轉成現場可驗證的文件、設備、測試或操作證據。

HOW TO READ THE REPORT

1. 文件架構與使用方式

LR 將法規狀態分為以下四個主要部分：

  1. Part 1｜已生效、但仍處於全面適用過渡期的要求
    已正式生效，但部分船舶會因船型、噸位、建造日期、設備安裝日期或首次定期檢驗日期而較晚適用。

  2. Part 2｜已通過、未來將生效的要求
    IMO／ILO 已採納，且已有確定的生效日期。

  3. Part 3｜正在制定中的要求
    尚未正式採納，文件提供預估生效日期，內容可能繼續修改。

  4. Part 4｜擬議中的新要求
    尚處於議題建立或初期提案階段，適用範圍與技術要求多半尚未確定。

EXECUTIVE TAKEAWAYS

2. 三分鐘結論

2.1 2026–2028 年最直接影響貨櫃船的要求

  • 2026 年起，船上起重設備與鬆散屬具須依新 SOLAS II-1/3-13 管理；既有設備亦須在指定換證檢驗前完成負荷試驗、徹底檢查、SWL 標示及文件化。
  • 含 PFOS 的消防泡沫自 2026 年起禁止使用與攜帶，新、舊船均須在首次相關法定檢驗時確認移除。
  • 加拿大北極與挪威海 ECA 已建立；NOx Tier III 適用於符合建造日期條件的新船，SOx 0.10% 要求自 2027 年起適用。
  • 2027 年起 NOx Technical Code 將增加重大改造引擎重新認證程序，以及多重運轉模式／排放控制策略要求。
  • 2028 年起，新造 20,000GT 以上非油輪須配置緊急拖帶裝置。
  • 2028 年起，領港登離船設備將採更完整且強制性的性能標準；既有設備也有追溯改善時程。
  • IMDG Code 43-26 對鋰金屬電池、鈉離子電池、車輛及貨櫃運輸單元提出新條文，對貨櫃船貨物接受與危險品文件管理尤其重要。

2.2 2028–2032 年最值得提前規劃的議題

  • IMO Net-Zero Framework 尚未形成共識，但若於 2026 年底採納，可能於 2028 年中生效，將同時影響燃料選擇、資本支出、營運成本與合規成本。
  • BWM Convention 全面檢討將從「設備有裝、有證書」轉向「設備持續有效運作」；保養紀錄、故障通報、修復計畫、船員熟悉度與活性物質年度取樣會成為檢驗重點。
  • CII／EEXI 第二階段檢討已確定 2027–2030 年更嚴格的 CII Z factor；SEEMP 可能由年度評級管理轉為持續改善與更強的公司責任追蹤。
  • 貨櫃船甲板及貨艙火災偵測與控制預計在 2032 年前後形成新 SOLAS／FSS Code 要求，可能涵蓋紅外線熱像儀、貨艙與甲板固定式偵測、遙控水砲、水霧槍、艙口蓋保護等。
  • 電池作為主電源、非傳統推進／操舵系統、MASS、自主船舶、替代燃料消防均正在形成新的法規架構。

SURVEYOR PRACTICE

8. 貨櫃船新造船／驗船實務追蹤清單

本節為依原文件整理出的實務閱讀順序，屬於應用性歸納，而非原文另立的法規清單。

8.1 設計與圖審階段

  • 核對建造合約、安放龍骨、交船三個日期，避免因交船延誤觸發新要求。
  • 確認 EEDI Phase 3 設計降幅及 EEXI／CII 後續營運策略。
  • LNG／低閃點燃料船核對 IGF Code 2026 與 2028 的：
    • fuel containment 與 A-60／cofferdam
    • pressure relief
    • bunkering interface
    • ventilation
    • hazardous area classification
    • fuel supply redundancy
  • 2028 年後新造 20,000GT 以上貨櫃船，確認 emergency towing arrangement。
  • 領港梯、舷梯、組合式 pilot transfer arrangement 預留 2028 新標準。
  • 追蹤 2032 年貨櫃火災新要求，以免新造船在設計後期才追加固定偵測、水砲或艙口保護。

8.2 建造與設備安裝階段

  • 起重設備與 loose gear：SWL、負荷試驗、證書、永久標示及登錄。
  • 消防泡沫：確認無 PFOS，並提前盤點 PFAS 風險。
  • IHM：MD／SDoC 完整性、供應商資料、船廠編製與交船認證。
  • 水位探測器：多貨艙貨櫃船不得只以傳統 bilge alarm 取代。
  • LNG 燃料系統：加注壓力相容性、DBB 間通風、氣體偵測、PRV 排放與危險區域。
  • IMO DCS、SEEMP、BWMP、BWRB 等船上文件應使用最新格式。

8.3 海試、交船與初次檢驗

  • 緊急拖帶、操舵、倒車與停船性能應保留完整測試證據。
  • 領港設備、起重設備、救生設備與消防系統確認實體配置、操作程序、證書及維護週期一致。
  • BWMS 不只確認 commissioning test，也應檢查保養邏輯、警報、旁通、故障通報及 contingency procedure。
  • 確認 IHM、IAPP、IEEC、Cargo Ship Safety Equipment／Construction 等證書附件與設備現況一致。

8.4 營運船舶管理

  • PFOS 泡沫移除與岸上處置紀錄。
  • 繫泊設備原始設計概念、MBLSD、繩索識別與汰換紀錄。
  • 起重設備年度／定期檢查、徹底檢查、負荷試驗與 loose gear register。
  • ECA 航線規劃：加拿大北極、挪威海、東北大西洋的 NOx／SOx 適用日期。
  • 2027–2030 CII Z factor 加嚴對航速、航線、裝載率與改裝投資的影響。
  • BWM 2028 修正前，先建立可稽核的保養、故障、修復及船員熟悉紀錄。
