一、文件基本定位

本文件為 Lloyd’s Register，LR 針對使用 氣體燃料 gases 或 其他低閃點燃料 low-flashpoint fuels 船舶所制定的入級規則。文件名稱為：

Rules and Regulations for the Classification of Ships using Gases or other Low-flashpoint Fuels, July 2025
中文可理解為：LR 使用氣體或其他低閃點燃料船舶之入級規則，2025 年 7 月版。

LR-RU-012 是 Lloyd’s Register 將 IMO IGF Code 納入船級規則，並加入 LR 補充入級要求與燃料別附錄後，形成的低閃點燃料船舶入級規則文件。其內容涵蓋設計、建造、測試、操作與訓練相關要求；但操作、訓練與法定核可事項仍須依船旗國 Administration、IMO 文件與專案船級審查意見分開確認。

1

規範性質

LR 船級協會針對低閃點燃料船舶制定的入級規則。

2

法規基礎

將 IMO IGF Code 納入船級規則，並加入 LR 補充要求與燃料別附錄。

3

工程目標

確保低閃點燃料船舶達到與傳統燃油船相當的安全水準。

LR 燃料代號對照（LFPF yy）

本文件不是單純的 LNG 燃料船規範，而是 LR 針對 低閃點燃料船舶 建立的總體入級框架。下列為 LR-RU-012 中 LFPF(xx,yy) 與 GR(yy,z) 使用的 yy 燃料識別代號對照。

燃料類型 LR 代號 說明 本文是否展開
Natural Gas NG 天然氣，可為 LNG 或 CNG 型態 本文重點燃料之一
Ethane Gas EG 乙烷氣 補充列示，不作深入展開
Petroleum Gas PG 石油氣，包含 propane、butane 或其混合物；LPG 燃料在 LR-RU-012 中以 PG 表示 Appendix LR4
Methyl Alcohol ML 甲醇 Methanol Appendix LR1
Ethyl Alcohol EL 乙醇 Ethanol Appendix LR1
Hydrogen HY 氫燃料 Appendix LR3
Ammonia AM 氨燃料 Appendix LR2

二、與 IGF Code／船旗國／LR 的關係

1. 與 IMO IGF Code 的關係

IGF Code 全名為 International Code of Safety for Ships Using Gases or Other Low-Flashpoint Fuels， 中文可譯為 使用氣體或其他低閃點燃料船舶安全國際章程。

LR-RU-012 的核心，是將 IGF Code 的要求整合進 LR 入級規則。船舶若要取得 LR 低閃點燃料相關入級， 除了必須符合 IGF Code 的基本要求，也須符合 LR 在本文件中補充的入級要求。

2. 「LR」前綴條文的意義

文件中若某項要求前面標示 LR，代表該條文是 Lloyd’s Register 的船級補充要求，不一定是 IGF Code 原文。

實務上，送審時不能只看 IMO 原文，也必須檢查 LR 補充要求，尤其是燃料別附錄、入級符號、Gas Ready 描述與風險評估要求。

3. 三層責任關係

層級 角色 主要功能
IMO 制定 IGF Code 等國際安全章程 提供國際最低安全標準
船旗國 Administration 法規解釋與法定證書核發 決定船舶是否符合法定要求
LR 船級審查與入級規範執行 確認船舶符合 LR 入級規則與相關技術要求

三、適用範圍與不適用範圍

適用對象

  • LNG 燃料貨櫃船
  • LNG 燃料散裝船
  • LNG 燃料渡輪
  • 甲醇燃料船
  • 氨燃料船
  • 氫燃料船
  • LPG 燃料船
  • 預留未來使用替代燃料的 Gas Ready 船舶

需特別區分

本文件主要適用於使用氣體或低閃點燃料作為 船用燃料 fuel 的船舶，而非單純運載液化氣體作為貨物的船舶。

類型 適用法規邏輯
使用 LNG 作為船舶燃料 通常適用 IGF Code 與 LR-RU-012
運載 LNG 作為散裝貨物的 LNG carrier 通常適用 IGC Code 與液化氣體散裝船規範
特殊混合功能船型 需依 LR 與主管機關確認適用規則邊界
重要觀念：不能簡單地說「LNG 船都適用本規範」。重點要看 LNG 是作為 燃料 fuel，還是作為 貨物 cargo。

四、整份文件的總體架構

這份文件可以從「船舶生命週期」角度理解：先確認法規定位與適用範圍，再進入設計、建造、測試，以及入級規則所涵蓋的操作與訓練相關要求，最後依燃料種類查閱對應附錄。其中 Part C-1／Part D 的操作與訓練條文屬入級範疇，須與船旗國法定核可分開確認。

五、文件前置部分摘要

封面與出版資訊

封面說明本文件為 July 2025 版，主題是使用氣體或其他低閃點燃料船舶的 LR 入級規則。 此部分對確認適用版本、後續 Notice 修訂、合約日期、建造日期與交船日期非常重要。

A guide to the Rules and published requirements

此部分說明 LR 規則的發布與更新方式，重點包括：

  • LR 規則通常定期發布。
  • 兩次正式發布之間，可能以 Notices 方式修訂。
  • 特殊船型、特殊燃料、特殊配置或替代設計，可能需要提交 direct calculations 直接計算。
  • LR 可能使用其內部或認可的計算方法進行審查。
Preamble 前言

Preamble 是理解整份文件的關鍵，說明：

  • 本規範的目的，是確保低閃點燃料船舶可符合 IGF Code。
  • 本規範已納入發行時的 IGF Code 內容。
  • LR 額外要求會以前綴 LR 標示。
  • IGF Code 的法規解釋權仍屬船旗國或 Administration。
  • 天然氣要求最完整，其他低閃點燃料需透過替代設計或附錄要求證明等效安全。

六、Part A：General 一般規定

Part A 是整份規範的共同基礎，適用於所有氣體或低閃點燃料船舶。它處理的是： 這份規範怎麼用、哪些船適用、重要術語怎麼定義、替代燃料如何證明等效安全，以及整體安全目標是什麼。

Chapter 2：General 一般規定

小節 內容摘要 實務用途
2.1Application 界定適用範圍，主要適用於 SOLAS Chapter II-1 Part G 所涵蓋船舶。 判斷船舶是走 IGF Code／LR-RU-012，還是 IGC Code。
2.1-07Class notation 定義 LFPF(xx,yy) 與 GR(yy,z)。 用於船級證書、新造船合約、替代燃料預留與改裝規劃。
2.1-08Submission 說明燃料艙、測試程序、支撐計算、轉換說明等圖面與資料。 形成設計公司與船廠的送審文件清單。
2.2Definitions 定義 accident、bunkering、CNG、LNG、ESD、LEL、MAWP、MARVS 等。 建立後續條文解讀基準，避免審查誤判。
2.3Alternative Design 若燃料或系統未被具體涵蓋，需證明達到等效安全。 適用於甲醇、氨、氫、LPG 或新型燃料系統。

入級符號：LFPF(xx,yy)

LFPF 是 Low Flash Point Fuel 的縮寫，表示船舶低閃點燃料機械、系統與布置已依 LR 規範設計、建造、安裝與測試。

欄位 意義 例子
xx 適用規則識別 GF 表示依 LR-RU-012／IGF Code；GC 表示依 IGC Code
yy 燃料種類識別（fuel identifier） 見 LR 燃料代號對照表
例： LFPF(GF,NG) 依 LR-RU-012／IGF Code 入級的天然氣燃料船； LFPF(GF,ML) 甲醇燃料船； LFPF(GF,HY) 氫燃料船。
燃料代號提醒： LFPF notation 的天然氣正式代號為 NG（Natural Gas）。 LNG 與 CNG 是儲存或供應型態，不是 yy 欄位的燃料代號。

Gas Ready：GR(yy,z)

GR 是 Gas Ready 描述，不是正式入級符號，而是表示船舶已針對某種低閃點燃料完成部分預留、核准或安裝。

代號 意義
AApproval in Principle，原則性批准
SStructural Reinforcement Installed，結構補強已安裝
T1燃料艙具備未來轉換能力
T2燃料艙已安裝
P管路與燃料系統已安裝
E1設備／機械具備轉換能力
E2設備／機械已安裝
注意：Gas Ready 不代表船舶已可使用該燃料營運，也不代表未來一定能無條件取得 LFPF 入級。 若日後正式啟用該燃料，仍須依當時有效的 LR 規範、IMO 要求與主管機關要求重新審查。

重要術語整理

術語 中文說明 工程意義
Low-flashpoint fuel 低閃點燃料 閃點低於 SOLAS II-2/4 一般允許條件的氣體或液體燃料
Bunkering 燃料加注 從岸基、浮動設施或可攜式燃料艙向船舶供應燃料

當燃料、設備或系統偏離既有條文，或使用 IGF Code 尚未完整具體涵蓋的燃料時，必須透過 等效安全 equivalent safety 證明其符合本規範的目標與功能要求。

HAZID

Hazard Identification，危害辨識。

HAZOP

Hazard and Operability Study，危害與可操作性分析。

FMEA

Failure Mode and Effects Analysis，失效模式與效應分析。

爆炸分析，用於評估爆炸壓力與後果。

氣體擴散分析，用於判斷洩漏後氣體雲範圍。

七、Chapter 3–4：目標、功能要求與一般技術要求

Chapter 3：Goal and Functional Requirements

Chapter 3 是整份文件的安全哲學核心。它採用 目標型標準 goal-based approach，不只要求某個設備尺寸或布置，而是要求整體系統必須達成明確的安全功能。

  • 系統安全性、可靠性與可依賴性應等同於新型傳統燃油主機與輔機。
  • 燃料相關危害的機率與後果應透過布置、通風、偵測與安全動作降到最低。
  • 安全措施不得導致不可接受的動力喪失。
  • 危險區域應盡量限制。
  • 危險區域內設備應盡量減少，且必須適當認證。
  • 應防止爆炸性、可燃性或有毒氣體意外累積。
  • 系統元件應防止外部損傷。
  • 應降低危險區域內點火源。
  • 燃料儲存、供應與加注系統應能安全接收、保存與輸送燃料。
  • 必須配置控制、警報、監測、關斷、固定式氣體偵測與消防系統。
  • 技術文件應足以證明規範符合性。
  • 單一故障不得導致不安全或不可靠情況。
工程解讀：低閃點燃料船的安全，不是單靠燃料艙厚度、閥件等級或管路材料， 而是靠整個系統在洩漏、火災、爆炸、停電、閥件失效、通風失效、偵測器動作與 ESD 啟動時仍能受控。

Chapter 4：General Requirements

Chapter 4 是從 Chapter 3 的功能要求進一步進入具體設計前的總體安全要求。它通常與下列文件或分析連動：

安全分析文件

  • 風險評估報告
  • 爆炸分析
  • 氣體擴散分析
  • 替代設計等效安全證明

設計與控制文件

  • 危險區域圖
  • 系統安全概念
  • 布置圖
  • ESD cause-and-effect

八、Part A-1：天然氣燃料船專用要求

Part A-1 是本文件中最完整的技術主體，主要針對 天然氣（NG；可為 LNG 或 CNG 型態） 作為燃料的船舶。 其他低閃點燃料可參考其設計架構，但不能直接照搬，因為各燃料的火災、爆炸、毒性、低溫與洩漏特性不同。

Chapter 5

Ship Design and Arrangement 船舶設計與配置

規定燃料艙、機艙、tank connection space、fuel preparation room、bunkering station、居住區、控制站、危險區域與逃生通道的布置原則。

實務影響：直接影響 GA Plan、燃料艙位置、危險區域邊界、加注站位置與通風口配置。

Chapter 6

Fuel Containment System 燃料圍護系統

規定燃料艙型式、一次屏障、二次屏障、絕熱、interbarrier space、支撐、壓力釋放、裝載限制與低溫保護。

實務影響：用於審查 Type C tank、independent tank、membrane tank、LNG fuel tank 與二次屏障設計。

Chapter 7

Material and General Pipe Design 材料與一般管路設計

規定低溫材料、管路強度、壓力等級、雙層管、duct、焊接、閥件、防外部損傷與火災耐受性。

實務影響：是燃料供應管路、加注管路、GVU 管路、管架與穿艙件設計的主要依據。

Chapter 8

Bunkering 加注系統

規定 bunkering station、加注管路、加注控制、通訊、ESD、洩漏偵測、溢流保護與連接方式。

實務影響：對 truck-to-ship、shore-to-ship、ship-to-ship 加注作業特別重要。

Chapter 9

Fuel Supply to Consumers 對用戶之燃料供應

規定燃料從儲存艙到主機、輔機、鍋爐、燃料電池或其他消耗設備的供應系統。

實務影響：審查 FGSS、GVU、雙層管、master gas fuel valve、purging、venting 與壓力控制。

Chapter 10

Power Generation and Gas Consumers 推進、發電與燃料消耗設備

規定雙燃料主機、純氣體主機、輔機、鍋爐、燃料電池、燃氣渦輪與其他 gas consumer 的安全要求。

實務影響：重點在燃料切換、pilot fuel、engine shutdown、發電冗餘與單一故障安全。

Chapter 11

Fire Safety 消防安全

規定火災偵測、防火分隔、消防水、水霧、乾粉、固定式滅火系統，以及燃料相關區域防護。

實務影響：影響 Fire Control Plan、消防管路、加注站消防與 fuel preparation room 滅火配置。

Chapter 12

Explosion Prevention 防爆

規定危險區域分類、點火源控制、爆炸壓力釋放、氣體累積防止與安全距離。

實務影響：與 Hazardous Area Plan、防爆設備清單、爆炸分析與通風設計密切相關。

Chapter 13

Ventilation 通風

規定 tank connection space、fuel preparation room、bunkering station、duct、airlock 與機艙通風要求。

實務影響：影響風機容量、通風口位置、通風失效警報與自動關斷邏輯。

Chapter 14

Electrical Installations 電氣設備

規定危險區域內電氣設備的防爆型式、認證、安裝、電纜穿艙件、照明與電源安全。

實務影響：需與 IEC 60079、IEC 60092-502、防爆設備選型與危險區域分類一致。

Chapter 15

Control, Monitoring and Safety Systems 控制、監測與安全系統

規定氣體偵測、火災偵測、壓力／溫度／液位監測、警報、ESD、interlock 與 cause-and-effect。

實務影響：是 ESD logic、alarm list、FMEA、commissioning test 與 sea trial 的核心章節。

Bunkering 特別提醒：bunkering station 原則上應位於開敞甲板以確保自然通風。 若位於封閉或半封閉空間，需透過風險評估考量隔離、強制通風、洩漏偵測、airlock、CCTV 或直接視線監控。

九、Part B-1／Part C-1／Part D：製造、操作與訓練

入級範疇提醒： Part B-1 主要對應建造與測驗；Part C-1／Part D 雖涵蓋操作、演練與訓練相關要求，但並不表示所有營運、SMS 與法定訓練核可事項皆由 LR 入級直接管轄，仍須與船旗國 Administration 及專案審查意見分開確認。

Part B-1：Chapter 16 製造、工藝與測試

Chapter 16 的重點不是設計概念，而是確認實際建造出來的系統符合已核准設計。

主要內容

  • 洩漏測試
  • 雙層管或 duct 測試

  • PQR，Procedure Qualification Record

十、燃料別附錄要求

NG Natural Gas：天然氣燃料系統（可為 LNG 或 CNG 型態）

天然氣是 IGF Code 目前最完整涵蓋的燃料，因此 Part A-1 是 NG 天然氣燃料船的主體規範。

  • NG 燃料艙形式與位置（LNG 或 CNG 型態）
  • 燃料供應管路與 GVU
  • 雙層管或 duct
  • 通風與氣體偵測
  • bunkering station
  • 消防、防爆、控制監測與 ESD
  • LNG Bunker Delivery Note

Appendix LR1：甲醇／乙醇

適用於 Methyl Alcohol，Methanol 甲醇 與 Ethyl Alcohol，Ethanol 乙醇 作為船舶燃料的船舶。

  • 常溫液體，低溫風險較 LNG 小
  • 仍屬低閃點燃料，需控制可燃蒸氣
  • 甲醇具毒性，需重視人員暴露與防護
  • 重點在燃料艙、洩漏收集、通風、加注與 ESD
  • 燃料艙最大裝載與 filling limit 有特定限制

Appendix LR2：氨 Ammonia

氨燃料的主要問題不只是火災或爆炸，更是 毒性 toxicity。

  • 毒性區域圖與人員暴露風險
  • 氨氣偵測器位置與警報設定
  • 通風進口、居住區、控制站與機艙開口相對位置
  • PPE、呼吸器、逃生路線
  • vent outlet 排放位置
  • cause-and-effect diagram
  • 燃料供應系統安全順序關斷

Appendix LR3：氫 Hydrogen

氫燃料的核心風險是 易洩漏、可燃範圍寬、點火能低與爆炸風險。

  • 高壓氫或液氫儲存方式
  • 材料相容性
  • 氫偵測與火焰偵測
  • 通風與安全距離
  • 爆炸分析與危險區域分類
  • purging、venting 與 ESD
  • PFD、P&ID、HAZID、HAZOP、FMEA

Appendix LR4：LPG／PG

LPG 通常包括 propane 丙烷、butane 丁烷 或其混合物。

  • 蒸氣通常比空氣重
  • 洩漏後可能向低處流動並積聚
  • 需分析甲板凹陷、排水槽、艙底與通風死角
  • 重點在燃料艙、管路、閥件、洩漏偵測與隔離
  • 需要完整 P&ID、cause-and-effect、FMEA、操作手冊與測試計畫

1. 低閃點燃料船的核心風險

十二、不同使用者的實務應用

對船廠

  • 確認入級符號是 LFPF 或 GR
  • 確認燃料種類與對應附錄
  • 管路施工、焊接品質與材料證書
  • 壓力測試、洩漏測試與 ESD 測試
  • 第一次 bunkering 前測試
  • LR survey 節點與 sea trial 項目

對設計公司

  • 初期 GA 是否符合燃料艙與加注站布置要求
  • 危險區域是否合理
  • 通風口是否與居住區或控制站衝突
  • 燃料管路是否具備二次圍護
  • ESD cause-and-effect 是否清楚
  • 替代燃料是否有風險評估支持

對船東與船管公司

  • Gas Ready 不等於正式可營運
  • 日後改裝仍須重新審查
  • 船員是否具備相應訓練
  • bunkering procedure 是否完整
  • 演練是否納入 SMS
  • 船員是否理解毒性、爆炸與低溫風險

十三、易混淆觀念整理

1. LR-RU-012 不等於 IGF Code 原文

LR-RU-012 包含 IGF Code，也包含 LR 額外入級要求。看到 LR 前綴時， 表示該條文是 LR 補充要求。

2. 天然氣以外燃料不能直接套用天然氣規則
燃料 主要風險
NG Natural Gas（LNG／CNG 型態）低溫、可燃氣體、爆炸
甲醇可燃液體、毒性、火焰不易察覺
氨毒性、腐蝕、洩漏擴散
氫易洩漏、可燃範圍寬、點火能低、爆炸
LPG蒸氣較重、低處積聚、爆炸
3. Gas Ready 不是正式燃料入級

GR 只是描述船舶具備某些預留或安裝項目，不代表船舶可以實際使用該燃料營運。 正式使用低閃點燃料，仍須取得相應 LFPF 入級與主管機關核可。

4. 操作程序不能取代硬體安全要求

替代設計可以透過等效安全證明，但不能簡單以「船員操作程序」取代規範要求的設備、材料、隔離或安全系統。

5. 風險評估不是形式文件

風險評估會直接影響：

  • bunkering station 設計
  • fuel preparation room 布置
  • tank connection space 設計
  • 通風量與氣體偵測器位置
  • ESD 邏輯與危險區域分類
  • 防火分隔、vent outlet 位置與船員暴露風險

十四、建議學習路徑

第一階段：先看懂文件定位
閱讀 Preamble、Chapter 2 Application、Definitions、Alternative Design。
第二階段：掌握安全哲學
閱讀 Chapter 3 Goal and Functional Requirements 與 Chapter 4 General Requirements。
第三階段：進入天然氣燃料船主體設計
閱讀 Chapter 5–9，理解燃料儲存、加注、輸送與消耗端設計。
第四階段：補強安全系統
閱讀 Chapter 11–15，理解消防、防爆、通風、防爆電氣、控制監測與 ESD。
第五階段：理解建造與營運
閱讀 Chapter 16–19，理解施工、測試、操作、演練與訓練。
第六階段：依燃料查附錄
甲醇／乙醇查 LR1，氨查 LR2，氫查 LR3，LPG 查 LR4。

十五、總結與工程判斷

一句話總結：
LR-RU-012 是 Lloyd’s Register 將 IMO IGF Code 納入船級規則，並加入 LR 補充入級要求與燃料別附錄後，形成的低閃點燃料船舶入級規則文件。其內容涵蓋設計、建造、測試、操作與訓練相關要求；但操作、訓練與法定核可事項仍須依船旗國 Administration、IMO 文件與專案船級審查意見分開確認。

核心複習重點

  • 文件定位：LR 低閃點燃料船舶入級規則文件（納入 IGF Code＋LR 補充要求與燃料別附錄）。
  • 法規基礎：IGF Code 納入船級規則，並加入 LR 補充入級要求。
  • 責任切分：操作、訓練與法定核可須與入級範疇分開確認。
  • 適用對象：使用氣體或低閃點燃料作為船用燃料的船舶。
  • 重要區分：使用 LNG 作燃料不同於運載 LNG 作貨物。
  • 正式入級符號為 LFPF(xx,yy)。
  • Gas Ready 為 GR(yy,z)，但不是正式燃料入級。
  • 安全哲學：以目標型標準與等效安全為核心。
  • 主要風險：火災、爆炸、毒性、低溫、洩漏、失去動力、錯誤操作。
  • 設計重點：燃料艙、管路、加注、燃料供應、通風、防爆、消防、控制監測與 ESD。
  • 建造重點：焊接、材料、壓力測試、洩漏測試、ESD 測試與試車。
  • 操作重點：入級規則所要求之燃料處理手冊、加注程序、緊急程序、演練與維護。
  • 訓練重點：入級規則所涵蓋之低閃點燃料相關船員能力要求；STCW／船旗國要求另須確認。
